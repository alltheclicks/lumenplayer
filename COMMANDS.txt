------------------------------------------------------------
PR + GREPTILE CHECKLIST (1 TASK = 1 PR)
------------------------------------------------------------

KAD KRECES TASK
  1) Potvrdi task ID iz BACKLOG.md (npr. LP-0201)
  2) Kreiraj branch:
     git checkout -b codex/lp-0201-kratak-opis

TOKOM RADA
  - Radi samo scope tog taska
  - Ako vidis nesto van scope-a, ostavi za poseban task

PRE PR-a (OBAVEZNO)
  pnpm lint && pnpm typecheck && pnpm build

COMMIT + PUSH
  git add -A
  git commit -m "fix(web): LP-0201 kratak opis izmene"
  git push -u origin codex/lp-0201-kratak-opis

OTVARANJE PR-a
  - Base: main
  - Compare: codex/lp-0201-kratak-opis
  - U PR opisu navedi:
    - sta je uradjeno
    - sta NIJE uradjeno
    - kako je testirano

GREPTILE FLOW
  1) Sacekaj komentare na PR
  2) Popravi validne komentare
  3) Ponovo:
     pnpm lint && pnpm typecheck && pnpm build
  4) Commit + push fix:
     git add -A
     git commit -m "fix: address Greptile review"
     git push
  5) Ako je komentar false-positive:
     - oznaci ga kao resolved / odgovori kratkim obrazlozenjem

POSLE MERGE-a (CISCENJE)
  git checkout main
  git pull --rebase
  git branch -d codex/lp-0201-kratak-opis
  # remote branch obrisi preko GitHub "Delete branch" dugmeta

  - Branch je privremen: koristi se do merge-a, pa se brise
