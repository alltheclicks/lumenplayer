## Important Runtime Semantics

- Live remains more tolerant in browser playback:
  - retry/recovery is acceptable for transient provider/network issues.
- Catch-up is stricter:
  - it starts from an archived timestamp,
  - old provider samples can become stale quickly,
  - the current browser runtime result is the source of truth.
- Static MP2/HEVC entries must not be treated as permanent truth because the beta provider changes sources several times per week.
- The dynamic cache is intentionally short so provider fixes are not blocked for long.
