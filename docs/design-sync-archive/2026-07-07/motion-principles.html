Motion — Principi i tokeni

Motion komunicira stanje — fokus, učitavanje, prelaz. Ništa se ne mrda bez razloga. Isključivo CSS; animira se samo transform i opacity. Tokeni žive u foundations/tokens.css.

Skala trajanja — pređi mišem za trku

--motion-instant · 80ms
--motion-fast · 140ms
--motion-base · 220ms
--motion-slow · 360ms
--motion-slower · 560ms

Instant = prvi feedback (<100ms). Fast = hover/press. Base = enter/reveal. Slow = overlay i show kontrola. Slower = exit kontrola, ambient, zap.

Reduced motion: sve trke se gase; stanja se menjaju trenutno.

Easing krive — isto trajanje, drugačiji karakter

--ease-out-soft
--ease-in-out-soft
--ease-exit
--ease-spring

--ease-spring koristi CSS linear() spring aproksimaciju (Chromium) sa cubic-bezier fallback-om — suptilan overshoot, nikad gumeno. Enter → out-soft; glide pozicije → in-out-soft; hide → exit.

Reduced motion: gasi se; krive nemaju semantičko značenje bez kretanja.

Koreografija

Stagger — 30ms korak
delay: calc(var(--i) * var(--motion-stagger))

Kaskada 20–40ms po stavci; nikad više od ~8 vidljivih koraka.

Reduced motion: lista se pojavljuje odjednom, bez kaskade.

Enter brži od exit
enter: base/out-soft · exit: slower/exit
pređi mišem — pusti da vidiš izlaz
UI odgovara odmah, povlači se diskretno

Ono što korisnik traži stiže brzo; ono što odlazi ne otima pažnju.

Reduced motion: panel se pali/gasi trenutno.

−4px · dovoljno
−28px · previše

Distanca pomeraja je mala: 4–12px za UI, ≤ jedne širine kartice za trake. Veliki skokovi deluju jeftino.

Reduced-motion politika

Svaka kartica u sistemu dokumentuje svoje prefers-reduced-motion ponašanje. Globalno pravilo: gase se sve tranzicije, kaskade, pulsevi i auto-petlje; ostaju trenutne promene stanja (fokus prsten, boje, prikaz/sakrivanje kontrola kao instant flip). Ništa funkcionalno ne sme zavisiti od animacije.
